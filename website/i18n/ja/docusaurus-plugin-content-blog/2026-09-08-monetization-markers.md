厳選されたツールリストも、コストについて何も語らなければ、その有用性は半分にしかなりません。「ワークフロー自動化には
n8n を使いましょう」という一文も、無料版ではオーナーアカウントが 1 つだけで、管理者 (admin) ロール自体が有料で
販売されていると知れば印象がまったく変わります。自分たちのインスタンスの管理をチームで分担することさえ、
エンタープライズプランに移行しなければできません——シングルサインオンも同じくそこにあります。そして
「オブジェクトストレージには MinIO を使いましょう」という一文も、コミュニティ版が有料版の機能を提供しなくなったと知れば
意味合いが一変します。8 月の更新以降、3,430 件のスキル項目すべてをこの観点で見直し、商用製品に該当する項目には
マーカーを付けるようにしました。

## 3 つのマーカー

凡例は現在、[イントロダクション](/docs/intro) の冒頭に掲載されており、マーカーは項目名の直前に配置されます。

- 🔒 **オープンソースまたはソースアベイラブルだが、価値の大部分が有料プランの背後に制限されているもの。**
  コードは公開されていますが、ベンダーは意味のある機能をライセンスの向こう側に留めています。n8n、Odoo、
  Metabase、MinIO、Neo4j、SonarQube Server。
- 💲 **実質的に無料では利用できない、プロプライエタリな商用製品またはクラウドサービス。** 計画に組み込めるような
  恒久的な無料枠はありません。Amazon RDS、Azure Monitor、Datadog、Salesforce、1Password。
- 🪙 **フリーミアム: 無料でも十分に利用でき、有料プランや周辺的な収益化にとどまるもの。** 実際に構築の土台に
  できる本物の無料プランがあります。Vercel、Cloudflare、AWS Lambda、Auth0、GitHub Copilot。

マーカーのない項目は、重大なペイウォールのない無料のオープンソースソフトウェアであるか、そもそも製品ではないもの
——概念、標準、プロトコル、Wikipedia の記事などです。項目のおよそ 10 件に 9 件はマーカーなしであり、これ自体が
重要な点です。本リストは設計上オープンに偏っており、マーカーは例外を可視化することで、調達の段階になって初めて
発覚する事態を避けています。

## 線引きの考え方

3 分類は議論を呼びやすいため、その判断根拠を明記しておく価値があります。

- **オープンコアは 🔒 に該当し、別立ての商用製品はそうではありません。** Sidekiq、Strapi、Kong、Gatling は
  インストールする製品自体の内部で機能を制限しているため、マーカーが付いています。Grafana、Cilium、Calico、
  NGINX、Ansible にはマーカーがありません。それぞれにエンタープライズプラットフォームを別途販売するベンダーが
  存在しますが、ほとんどの人にとっては無料版がツールのすべてだからです。
- **恒久的な無料枠があれば 🪙 になり、トライアルでは付きません。** AWS Lambda、Cloud Run、Azure Container
  Apps、DynamoDB、BigQuery にはいずれも常時無料の枠があり、実際のプロジェクトがその範囲内で稼働しています。
  Amazon EC2 の 12 か月間の無料枠は期限付きで失効するため、EC2 は 💲 です。
- **ダウンロード自体が無料でも、ライセンス条件による制限は「ゲーティング」とみなします。** Ultralytics YOLO は
  AGPL-3.0 で、クローズドソースソフトウェアに組み込んで出荷するには有料ライセンスが必要です。CodeQL は
  オープンソース向けにのみ無料です。どちらも 🔒 であり、そのダウンロードページが示す以上に重要な意味を持ちます。
- **判断基準は「ツールの価格」ではなく「実行に何が必要か」です。** Claude Code と OpenAI Codex は有料プラン
  または API クレジットを必要とするため 💲 です。Aider、Cline、Crush にはマーカーがありません。自分の
  API キーを持ち込む方式であり、ハーネス自体にはペイウォールがないためです。

中には本当に議論の余地がある判断もあります。Amazon VPC およびその Azure・Google における同等サービスには
💲 マーカーが付いていますが、ネットワークオブジェクト自体は無料です。これは、有料のクラウドアカウント内でのみ
存在し、実際には NAT やアウトバウンド通信で課金が発生するという理由によるものです。Terraform と Packer は
🔒 です。これは CLI が機能制限されているからではなく、BUSL の下でソースアベイラブルであり、有料の HCP プランが
存在するためです。MySQL は、MySQL Enterprise Edition が監査機能や暗号化を制限しているにもかかわらず、NGINX
と同じ理由によりマーカーなしとしています。

マーカーはすべて、日本語訳にもそのまま反映されます。この規約はリポジトリの `CLAUDE.md` に記録されており、
新規項目が改めて一括見直しを必要とせず、最初からマーカー付きで追加されるようにしています。
