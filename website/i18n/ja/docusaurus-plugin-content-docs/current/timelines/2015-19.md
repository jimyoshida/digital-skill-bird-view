# タイムライン - 2015-19

## 2015

🏢 2013 年までに、Prometheus は SoundCloud での本番環境監視のために導入されました。公式な公開発表は 2015 年 1 月に行われました。

📊 Project Jupyter は、複数のプログラミング言語にわたるインタラクティブコンピューティングのための、オープンソースソフトウェア、オープン標準、およびサービスを開発するプロジェクトです。2014 年に Fernando Pérez と Brian Granger により IPython からスピンオフされ、2015 年 2 月に正式に設立されました。

🧠 Keras は、Python インターフェースを人工ニューラルネットワークに提供し、TensorFlow ライブラリのインターフェースとして機能するオープンソースソフトウェアライブラリで、2015 年 3 月 27 日に初回リリースされました。

🖥️ 2015 年 4 月 8 日、GitHub は Git Large File Storage (Git LFS) を発表しました。これにより、ユーザーは Git に大きなバイナリファイルを保存および操作できるようになります。

🖥️ Visual Studio Code は Microsoft により開発されたソースコードエディターで、Windows、Linux、および macOS に対応しており、2015 年 4 月 29 日に Build カンファレンスで最初に発表され、その直後にプレビュービルドがリリースされました。

⚙️ 2015 年 4 月、Debian 8.0 (Jessie) は systemd をデフォルトの init システムとしてリリースされました。同じ月に、Ubuntu 15.04 も systemd への正式な切り替えとしてリリースされました。

🌐 Discord は 2015 年 5 月 13 日に公開リリースされました。ゲーミングコミュニティがゲームプレイ中に通信するために設計されたプラットフォームです。

📜 最初の安定版リリース Rust 1.0 は 2015 年 5 月 15 日に発表されました。

📜 第 6 版である ECMAScript 6 (ES6) は、後に ECMAScript 2015 に改名され、2015 年 6 月に完成しました。クラス宣言や ES6 モジュールなど、複雑なアプリケーションを作成するための重要な新しい構文が追加されました。ES6 は「アロー関数」構文をサポートしており、=> シンボルは無名関数のパラメータリストと本体を区切ります。

☁️ Open Container Initiative (OCI) は 2015 年 6 月 22 日に DockerCon で Docker、CoreOS、およびその他の業界指導者により Linux Foundation の下で起動されました。オペレーティングシステムレベルの仮想化のためのオープン標準を設計するためです。
OCI は、仕様を実装し、他の高レベルツールの基礎として機能するコンテナランタイム runc を開発しています。runc は 2015 年 7 月にバージョン 0.0.1 として最初にリリースされました。

🧠 Amazon Echo と Alexa は、2014 年 11 月の限定リリースを経て、2015 年 6 月 28 日に米国で正式にローンチしました。

🏢 Kubernetes 1.0 は 2015 年 7 月 21 日にリリースされました。Google は Linux Foundation と協力して Cloud Native Computing Foundation (CNCF) を設立し、Kubernetes をシード技術として提供しました。

⚙️ Windows 10 は 2015 年 7 月 29 日にリリースされ、継続的な更新により「Windows as a Service」モデルが導入され、Windows 8 のタイルベースの実験の後にスタートメニューが復元され、Microsoft Edge ブラウザーと Cortana 仮想アシスタントが統合されました。

📜 Go 1.5 は 2015 年 8 月 19 日にリリースされました。これは、コンパイラーとランタイムツールチェーン全体が C から Go に書き直された画期的なリリースで、言語をセルフホスティングするようになりました。

🌐 Phoenix v1.0 は 2015 年 9 月 1 日にリリースされ、生産性が高く信頼性のあるウェブフレームワークを提供し、Elixir エコシステムの基礎となりました。

🔐 FIDO2 Project は、FIDO Alliance と World Wide Web Consortium (W3C) の共同作業です。ウェブのための強力な認証を作成することを目指しています。FIDO2 の中核は W3C Web Authentication (WebAuthn) 標準と FIDO Client to Authenticator Protocol 2 (CTAP2) で構成されており、FIDO 2.0 提案標準は 2015 年 9 月 4 日にリリースされました。

🏢 2015 年 9 月 14 日、Let's Encrypt はドメイン helloworld.letsencrypt.org の最初の証明書を発行しました。同じ日に、ISRG はその root プログラム申請書を Mozilla、Microsoft、Google、および Apple に提出しました。

🏢 2015 年 9 月に、Node.js v0.12 と io.js v3.3 は Node v4.0 にマージバックされました。

🌐 Vue.js は、ユーザーインターフェースとシングルページアプリケーションを構築するための、Evan You により作成されたオープンソースモデル - ビュー - ビューモデルフロントエンド JavaScript フレームワークです。プロジェクトの最初のソースコードコミットは 2013 年 7 月にさかのぼり、Vue は 2014 年 2 月に最初にリリースされ、Vue.js 1.0 は 2015 年 10 月 27 日にリリースされました。

☁️ Serverless Framework は、Node.js を使用して作成された無料でオープンソースのウェブフレームワークで、AWS Lambda でアプリケーションを構築するために開発された最初のフレームワークです。Austen Collins により開発され、フルタイムチームにより保守されており、2015 年 10 月に初回リリースされました。

🖥️ Neovim の最初の公式リリースは 2015 年 11 月 1 日に行われ、モダンな機能と組み込み可能性に重点を置いた、リファクタリング済みで拡張性の高い Vim のフォークを提供しました。

🧠 TensorFlow は、機械学習および人工知能のための無料でオープンソースのソフトウェアライブラリで、様々なタスクの間で使用可能ですが、ディープニューラルネットワークのトレーニングと推論に特に焦点を当てており、2015 年 11 月 9 日に初回リリースされました。

🏢 2015 年 11 月 18 日、Visual Studio Code のソースは MIT ライセンスの下でリリースされ、GitHub で利用可能になりました。

🏢 2015 年 11 月 18 日、Microsoft は Visual Studio Online が「Visual Studio Team Services (VSTS)」に改名されたことを発表しました。

📜 Python は 2015 年バージョン 3.5 で async / await のサポートを追加しました。

📜 TypeScript は 2015 年バージョン 1.7 で async / await のサポートを追加しました。

🏢 Cloud Native Computing Foundation (CNCF) は、2015 年に設立された Linux Foundation プロジェクトで、コンテナ技術の進歩を支援し、その進化の周りに技術業界を整列させるためです。

🌐 2015 年に発行された HTTP / 2 は、HTTP のセマンティクスを「オンザイア」でより効率的に表現します。

☁️ Envoy はネットワークをアプリケーションから透過的にする高性能なオープンソースのエッジおよびサービスプロキシで、アーキテクチャをモノリスから脱却させるために Lyft で開発されました。開発は 2015 年に始まり、2015 年の晩秋には Lyft のトラフィックの 100% を処理するようになりました。

## 2016

☁️ 2016 年 2 月に、Kubernetes 向けパッケージマネージャー Helm がリリースされました。

☁️ Google Cloud Functions はサーバーレス実行環境で、2016 年 2 月にアルファで利用可能になりました。

☁️ Azure IoT Hub は 2016 年 2 月 4 日に一般提供に達し、IoT アプリケーションとデバイス間の双方向通信のための中央メッセージハブを提供しました。

☁️ Kubernetes 1.2 は 2016 年 3 月にリリースされ、デプロイメントと最大 1,000 ノードのクラスターのサポートが導入されました。

🧩 2014 年 8 月 15 日に npm に公開された、文字列をパディングする 11 行の JavaScript ユーティリティパッケージ `left-pad` は、Azer Koçulu によって作成され、月間 1,500 万回以上ダウンロードされるようになり、Babel、Webpack、React などの主要プロジェクトが依存するようになりました。npm が彼の `kik` パッケージ名の所有権を 2016 年 3 月 18 日に Kik Interactive に移管する紛争の後、Koçulu は抗議として 2016 年 3 月 22 日に自身の 273 個の npm パッケージすべての公開を取り消し、Facebook、PayPal、Netflix、Spotify などを含む数千のプロジェクトのビルドが数時間のうちに JavaScript エコシステム全体で破損しました。

🧩 npm は `left-pad` パッケージの公開が取り消されてから数時間後の 2016 年 3 月 22 日に、バックアップからバージョン 0.0.3 を手動で再公開して復元しました。同社はその後、他のパッケージが依存している場合にパッケージの公開を取り消せないようポリシーを変更しました。

🖥️ Visual Studio Code は公開プレビュー段階から卒業し、2016 年 4 月 14 日にバージョン 1.0 に到達しました。その時点で 1,000 を超える拡張機能と 50 万人のアクティブユーザーを擁していました。

🔐 General Data Protection Regulation (略して GDPR、またはフランス語の RGPD) は、欧州連合 (EU) および欧州経済領域 (EEA) における情報プライバシーに関する欧州連合規則です。
欧州議会および欧州連合理事会は 2016 年 4 月 14 日に GDPR を採択し、2018 年 5 月 25 日に有効になりました。

☁️ 2016 年 4 月 20 日、Jenkins バージョン 2 は Pipeline プラグインがデフォルトで有効になってリリースされました。このプラグインにより、Apache Groovy に基づくドメイン固有言語を使用してビルド指示を作成できます。

⚙️ Snap は、Linux カーネルと systemd init システムを使用するオペレーティングシステム向けに Canonical により開発されたソフトウェアパッケージング展開システムです。
最初の snapd 2.12 は Ubuntu 16.04 (xenial-updates) および Fedora 24 にリリースされました。

🔐 Web Authentication (WebAuthn) は、World Wide Web Consortium (W3C) により発行されたウェブ標準です。WebAuthn は FIDO Alliance のガイダンスの下で FIDO2 Project のコアコンポーネントです。
最初の発行：2016 年 5 月 31 日

🏢 2016 年 5 月に、Cloud Native Computing Foundation は Prometheus を Kubernetes に続く 2 番目のインキュベートプロジェクトとして受け入れました。

🌐 ASP.NET Core は、Microsoft により開発されたオープンソースウェブフレームワークおよび ASP.NET の後継者で、2016 年 6 月 7 日に初回リリースされました。

📜 Yarn は、2016 年に Facebook により Node.js JavaScript ランタイム環境向けに開発されたソフトウェアパッケージングシステムで、2016 年 6 月 18 日に初回リリースされました。

📜 \.NET Core 1.0 は 2016 年 6 月 27 日にリリースされました。同時に、Microsoft Visual Studio 2015 Update 3 がリリースされました。これにより \.NET Core 開発が可能になります。

🖥️ Language Server Protocol (LSP) は、ソースコードエディターまたは統合開発環境 (IDE) とプログラミング言語固有の機能を提供するサーバーの間で使用するための、オープンな JSON-RPC ベースのプロトコルです。元々 Microsoft Visual Studio Code 向けに開発され、現在はオープン標準です。2016 年 6 月 27 日、Microsoft は Red Hat および Codenvy との協力を発表し、プロトコル仕様を標準化しました。

🖥️ VS Code Go 拡張は Go プログラミング言語に豊富な言語サポートを提供し、2016 年 7 月に初回リリースされました。

☁️ Prometheus 1.0 は 2016 年 7 月にリリースされました。その後のバージョンは 2016 年と 2017 年を通じてリリースされ、2017 年 11 月に Prometheus 2.0 が主導しました。

⚙️ Windows Subsystem for Linux (WSL) は、Windows で ELF 形式の Linux バイナリ実行可能ファイルをネイティブに実行するための互換性レイヤーです。
WSL ベータは 2016 年 8 月 2 日に Windows 10 バージョン 1607 (Anniversary Update) で導入されました。デフォルトシェルとして Bash を使用する Ubuntu のみがサポートされていました。

🖥️ Microsoft は 2016 年 8 月 18 日に PowerShell がオープンソース (MIT ライセンスの下) およびクロスプラットフォーム化されていることを発表し、Linux および macOS のアルファバージョンがリリースされました。

☁️ Lyft は 2016 年 9 月 14 日に Envoy をオープンソース化し、大規模なサービス指向アーキテクチャ向けに設計された C++ 製の L7 プロキシおよび通信バスとして発表しました。バージョン 1.0.0 はその 2 日前にタグ付けされていました。

⚙️ macOS 10.12 Sierra は 2016 年 9 月 20 日にリリースされました。Apple はオペレーティングシステムを「OS X」から「macOS」に改名し、他のオペレーティングシステム (iOS、watchOS、tvOS) のブランディングと合わせました。また、初めて Mac で Siri を導入しました。

☁️ Cilium 0.1 は 2016 年 9 月にリリースされました。eBPF を活用してコンテナ化されたワークロード向けに高性能ネットワーク、セキュリティ、および可観測性を提供するクラウドネイティブプロジェクトです。

🌐 Angular は、Google の Angular Team およびユーザーと企業のコミュニティにより主導される TypeScript ベースのオープンソースウェブアプリケーションフレームワークです。Angular 2.0 は 2014 年 10 月 22 - 23 日に ng-Europe カンファレンスで発表され、2.0 バージョンの大きな変更は開発者間でかなりの論争を引き起こしました。バージョン 2.0 は 2016 年 9 月 14 日にリリースされました。

🧠 PyTorch は Torch ライブラリに基づいた機械学習フレームワークで、コンピュータービジョンと自然言語処理などのアプリケーション向けに使用されており、元々 Meta AI により開発され、現在は Linux Foundation の傘下の一部です。初回リリースは 2016 年 9 月でした。

🎨 Figma は 2016 年 9 月 27 日に初めて一般公開され、ブラウザベースのコラボレーティブなインターフェースデザインツールとしてローンチしました。

🏢 Google Apps は 2016 年 9 月 29 日に G Suite に正式に改名され、クラウドベースの生産性ツールの協調的かつインテリジェントな性質を強調しました。

🌐 Next.js は、Vercel により作成されたオープンソースウェブ開発フレームワークで、React ベースのウェブアプリケーションをサーバーサイドレンダリングして静的ウェブサイトを生成することを可能にし、2016 年 10 月 25 日に初回リリースされました。

🌐 Nuxt.js は、Vue.js、Node.js、Webpack、および Babel.js に基づく無料でオープンソースの JavaScript ライブラリで、React.js ベースの同様の目的のフレームワークである Next.js に触発され、2016 年 10 月 26 日に初回リリースされました。

🌐 HTML 5.1 は 2016 年 11 月に W3C 勧告として発行され、レスポンシブ画像向けの `<picture>` 要素、`<details>` および `<summary>` 要素、および `inputmode` 属性などの機能が追加されました。

🏢 Microsoft は 2016 年 11 月 15 日に Azure Functions の一般提供可能性を発表しました。

🏢 Hugging Face、Inc. は、機械学習を使用したアプリケーション構築用のコンピューション ツールを開発するニューヨーク市に本拠地がある米国企業です。同社は 2016 年に設立され、元々はティーンエイジャーを対象とした チャットボット アプリを開発していた企業としての始まりでした。Hugging Face Hub は、集中型ウェブサービスとしてのホスティングを提供するプラットフォームです。

## 2017

🌐 k6 は 2017 年 2 月に Load Impact によりオープンソース化されました。Go で書かれた JavaScript スクリプト機能を備えた最新のロードテストツールで、開発者ワークフローと CI / CD 統合用に設計されています。Load Impact はその後 2020 年に k6 に改名され、2021 年に Grafana Labs により買収されました。

🌐 WebAssembly (時々 Wasm と略されます) は、ポータブルバイナリコード形式と実行可能なプログラム用の対応するテキスト形式を定義しています。
2015 年に発表され、2017 年 3 月に最初にリリースされました。

🏢 Google は 2017 年 3 月にデータサイエンティストと機械学習実践者の世界最大のコミュニティである Kaggle を買収しました。

☁️ Kubernetes 1.6 は 2017 年 3 月にリリースされ、Role-Based Access Control (RBAC) が導入され、etcd v3 がデフォルトストレージバックエンドになりました。

🧠 DVC は、無料でオープンソースのプラットフォーム非依存バージョンシステムで、データ、機械学習モデル、およびテスト用です。ML モデルを共有可能にし、テストを再現可能にし、モデル、データ、およびパイプラインのバージョンを追跡するために設計されており、2017 年 5 月 4 日に初回リリースされました。

📊 Azure Cosmos DB は、グローバルに分散したマルチモデルデータベースサービスで、2017 年 5 月 10 日に一般提供に達しました。

☁️ 2017 年 5 月 24 日、Google、IBM、Lyft はマイクロサービスを統一的に接続、保護、管理、監視する方法を提供するオープンソースプロジェクト Istio の最初の公開リリースを発表しました。Lyft の Envoy プロキシを用いて構築されており、アプリケーションコードを変更することなくトラフィックの可視性と制御を提供します。

☁️ Google Cloud IoT Core は 2017 年 5 月にベータで起動され、IoT デバイスの接続と管理を行います。

🐛 WannaCry ランサムウェア攻撃は 2017 年 5 月の世界中のサイバー攻撃で、WannaCry ランサムウェア暗号ワームによるもので、Microsoft Windows オペレーティングシステムを実行しているコンピューターを対象とし、データを暗号化して Bitcoin 暗号通貨での身代金支払いを要求しました。

☁️ Kubernetes 1.7 は 2017 年 6 月にリリースされ、Third Party Resources (TPR) の置き換えとして Custom Resource Definitions (CRD) が導入されました。

🏢 「Microsoft 365」ブランドは 2017 年 7 月 10 日に Microsoft Inspire で初めて導入されました。Office 365 と Windows 10 Enterprise ライセンスおよび Enterprise Mobility + Security (EMS) をバンドルしたエンタープライズサブスクリプション製品です。

⚙️ 2017 年 7 月 14 日、 RFC 2460 に代わる RFC 8200 の発行により、 IPv6 はインターネット標準（ Internet Standard ）として承認されました。

☁️ OCI v1.0 は 2017 年 7 月 19 日に公式にリリースされました。これはランタイムとイメージ仕様の安定化を示しています。runc 1.0 は OCI Runtime Specification の参考実装で、同じ日にリリースされました。

🌐 2017 年 7 月、Adobe は 2020 年末までに Flash Player を完全に廃止する (セキュリティ更新を含む) ことを発表し、すべての主要ブラウザーとプラットフォームに削除計画の最終化を促しました。

📊 Apache Iceberg は、巨大な分析テーブル向けのオープンソース高性能フォーマットで、Spark、Trino、Flink、Presto、Hive、Impala、StarRocks、Doris、および Pig などのエンジンが同じテーブルに安全に同時に機能できるようにしながら、SQL テーブルをビッグデータに使用することを可能にしており、2017 年 8 月 10 日に初回リリースされました。

📜 2017 年 9 月 12 日、Oracle Corporation は Java EE を Eclipse Foundation に提出することを発表しました。そこで、Oracle が「Java」商標を保持していたため、後に Jakarta EE に改名されました。

☁️ Lyft は 2017 年 9 月 13 日に Envoy を Cloud Native Computing Foundation に寄贈し、インキュベーションの成熟度レベルで受け入れられました。

🌐 Java 9 は 2017 年 9 月 21 日にリリースされ、Java Applet API (`java.applet` パッケージ) を公式に非推奨にし、Java プラットフォーム内でのアプレットサポートの正式な終了を示しました。

🌐 Cypress は 2017 年 5 月 4 日にオープンソース化されることを発表し、2017 年 10 月 10 日に公開ベータに入りました。単一のモノレポに再構築され、npm 経由でインストール可能な Node.js モジュールとして利用可能になり、3 年間の非公開開発を終了しました。

⚙️ WSL は 2017 年 10 月 17 日にリリースされた Windows 10 バージョン 1709 (Fall Creators Update) でベータではなくなりました。複数の Linux ディストリビューションをインストールでき、Windows Store でインストール用に利用可能でした。

⚙️ Ubuntu 17.10 (Artful Aardvark) は 2017 年 10 月 19 日にリリースされました。GNOME Shell インターフェースを使用する初めてのリリースであり、X11 ウィンドウシステムを Wayland ディスプレイサーバーに置き換えました。デフォルトでは、この変更は Unity をデフォルトのデスクトップとして使用してから約 6.5 年後に発生しました。

🏢 2017 年 10 月終わりに Microsoft は AKS (Azure Container Service) のプレビューを発表しました。これは Azure 内のマネージド Kubernetes サービスです。

⚙️ 2017 年 11 月 6 日、Amazon は KVM ハイパーバイザーの周辺のカスタムアーキテクチャーに基づいた新しい C5 インスタンスファミリー (Nitro と呼ばれる) を発表しました。

🌐 HTML 5.2 は 2017 年 12 月に W3C 勧告として発行され、`<dialog>` 要素と Payment Request API のサポートが追加され、古い機能が削除されました。

📜 ISO は 2017 年に PDF 2.0 を ISO 32000-2 として発行しました。これは Adobe プロプライエタリ拡張なしに ISO により完全に開発された PDF 仕様の最初のバージョンで、デジタル署名の改善、関連ファイル、および地理空間データのより良いサポートなどの新機能を導入しました。

🌐 WebAssembly System Interface (WASI) は、Mozilla により設計された単純なインターフェース (ABI および API) で、任意のプラットフォームにポータブルになることを意図しています。ファイル I / O などの POSIX のような機能をケイパビリティベースのセキュリティによって制約して提供しています。

📜 Javascript は 2017 年 ECMAScript 2017 JavaScript 版の一部として async / await のサポートを追加しました。

🧠 トランスフォーマーは、入力データの各部分の重要性に差をつけて重み付けする自己注意メカニズムを採用するディープラーニングモデルです。主に自然言語処理 (NLP) およびコンピュータービジョン (CV) の分野で使用されます。
トランスフォーマーは 2017 年に Google Brain のチームにより導入され、LSTM などの RNN モデルを置き換え、NLP 問題の選択モデルとなりつつあります。

🌐 Uvicorn は、Tom Christie により作成された Python 用の高速 ASGI (Asynchronous Server Gateway Interface) サーバー実装で、2017 年後期に最初にリリースされました。

🌐 Puppeteer は 2017 年に Google の Chrome DevTools チームによりオープンソース化されました。Chrome DevTools Protocol (CDP) 上の高レベル API を提供する Node.js ライブラリで、ヘッドレス Chrome と Chromium を制御します。Puppeteer 1.0 は 2018 年 1 月にリリースされ、JavaScript エコシステムでのヘッドレスブラウザー自動化の主流ツールになり、その後 Playwright の作成を触発しました。

## 2018

🖥️ PowerShell Core 6.0 は 2018 年 1 月 10 日に一般提供に到達しました。\.NET Core に基づいて構築され、Windows、macOS、および Linux でのクロスプラットフォーム使用向けに設計された初めてのシェルバージョンです。

☁️ 2018 年 1 月 15 日、AWS は AWS Lambda 向けに Go をサポートされた言語として発表しました。

🐛 Meltdown は 2 つの元々のトランジェント実行 CPU 脆弱性の 1 つです (もう 1 つが Spectre)。Meltdown は Intel x86 マイクロプロセッサー、IBM POWER プロセッサー、および一部の ARM ベースのマイクロプロセッサーに影響を与えます。不正なプロセスが権限がない場合でもすべてのメモリを読み取ることを可能にします。
発見日：2018 年 1 月

🐛 Spectre は、2 つの元々のトランジェント実行 CPU 脆弱性の 1 つ (もう 1 つが Meltdown) です。マイクロアーキテクチャーターミング サイド チャネル攻撃を含みます。これらは分岐予測およびその他の形式の推測を実行する最新のマイクロプロセッサーに影響を与えます。
発見日：2018 年 1 月

⚙️ OpenSSH ベースのクライアントおよびサーバープログラムは Windows 10 バージョン 1803 (2018 年 4 月更新) 以降に含まれています。

🖥️ Visual Studio Code 向けの Python 拡張は、Python 言語に豊富なサポートを備えた Visual Studio Code 拡張で、2018 年 2 月 2 日に初回リリースされました。

☁️ Argo CD は Kubernetes 向けの宣言的な GitOps 継続的デリバリーツールで、大企業のニーズに適合する Kubernetes ネイティブなソリューションとして Intuit で開発が始まりました。リポジトリは 2018 年 2 月 9 日に作成され、バージョン 0.1.0 が 2018 年 3 月 13 日にリリースされました。

🌐 Nest (NestJS) は効率的でスケーラブルな Node.js サーバーサイドアプリケーションを構築するためのフレームワークで、2018 年 2 月 16 日に GitHub で初回リリースされました。

📜 Deno は、V8 JavaScript エンジンと Rust プログラミング言語に基づいた JavaScript、TypeScript、および WebAssembly 向けのランタイムで、Node.js も作成した Ryan Dahl により共同作成され、2018 年 5 月 13 日に初回リリースされました。

🌐 Hypercorn は高性能 ASGI および WSGI ウェブサーバーで、HTTP / 1、HTTP / 2、および HTTP / 3 のサポート付きで、2018 年 6 月 2 日にオープンソースとしてリリースされました。
